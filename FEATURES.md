# What Steam has, and where it could go

Read from the live store on 2026-11-24, signed out. Items marked * need a login or the app, so they come from general knowledge and need checking.
The "Our place" column is a proposal.

## Store
| Feature | Our place |
|---|---|
| Home: featured, recommended, wishlist, DLC, categories, recently updated, community recommends, under 10€ | Home, reduced to one featured block and four tabs |
| Announcements and events (Steam Awards, Next Fest, sale events) | Home strip, and a News page |
| Charts: top sellers, most played | Browse |
| Popular new, upcoming, specials, trending free, all new releases | Browse, as sorting |
| Free to play, demos, early access, DLC, software, soundtracks | Browse, as a type filter |
| Categories and tags (action, strategy, co-op, horror and more) | Browse, as filters |
| Platform: macOS, SteamOS + Linux, VR, great on Deck | Browse, as filters |
| Price: under 5€, under 10€ | Browse, as a filter |
| Search and advanced search | Search, same results screen as Browse |
| Discovery queue, interactive recommender, community recommendations, random game, Steam Labs | One "Discover" feature inside Browse |
| Hardware | Browse menu |
| Gift cards, points shop | User menu |
| News hub | User menu and the home strip |

## Game page
| Feature | Our place |
|---|---|
| Trailer, screenshots, short description, price, buy, bundles and editions | Top of the page |
| Reviews (recent, all, language) and review list | Own section |
| Developer, publisher, release date, tags | Short facts list |
| Features: single-player, co-op, achievements, cloud, Workshop, trading cards, Remote Play, Family Sharing, accessibility | Short list, "show all" for the rest |
| DLC, languages, system requirements, about | Sections below, closed by default on phone |
| Curators, similar games | End of page |
| Wishlist, follow, ignore, share, embed | Wishlist as a button, rest in a small menu |
| Community hub link | Tab on the game page |

## Buying
| Feature | Our place |
|---|---|
| Wishlist with sale alerts* | Wishlist |
| Cart, gift a game*, checkout* | Cart (demo only, no checkout) |
| Wallet*, purchase history*, refunds | User menu, shown as a static screen or skipped |

## Library*
| Feature | Our place |
|---|---|
| Owned games, collections, recent play, install and play | Library |
| Achievements, playtime, cloud saves, updates | Game page inside Library |
| Downloads | Library |
| Family Sharing, Remote Play | Library game page |
| Steam Replay (year in review) | Profile |

## Community and user
| Feature | Our place |
|---|---|
| Profile, level and badges*, inventory*, trading* | Profile |
| Friends and chat*, groups* | Friends panel |
| Discussions, guides*, screenshots*, Workshop, broadcasts | Tab on each game page |
| Community Market | Later or skipped |
| Notifications* | Bell next to the cart |
| Language, settings, parental controls*, support, mobile app | User menu |
| Terms, privacy, cookies, accessibility | Footer |

## Suggested order
1. Home (built, first pass)
2. Game page
3. Browse and search
4. Wishlist and cart
5. Library
6. Profile and friends

## Suggested to skip
Market, trading, broadcasts, chat, payment, real login, developer tools.
